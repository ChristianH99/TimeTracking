The manager's counterpart of the month picker, and deliberately built to the same pattern: two arrows with a disclosure between them, **and everything in it is a link**. No form, no `` here would also repeat the fault the month picker was built to escape: a select whose selected option is missing shows the first entry instead and says nothing about it, which on this page would be one person's name over another person's hours. **Every link carries the month.** Stepping to the next person keeps September rather than dropping back to today: a manager reads down one month across the team, and a picker that reset the month would make that eleven navigations instead of ten. The arrows step through the same order the list is in — `Employee.Meta.ordering`, which is the order the People page uses — so "next" means the next name a manager would have found by scrolling. At the ends there is nothing to step to and the arrow is drawn as a dead one rather than wrapping round: a `›` on the last person that silently lands on the first is a control that lies about where it goes, and the disclosure beside it is how somebody gets back to the top. {% endcomment %}
